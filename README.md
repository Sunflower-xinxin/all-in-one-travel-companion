# All-in-One Travel Companion

**旅匣** — 把琐事装进行囊，把自由留给旅途。

A mobile-friendly, installable travel companion for transport, daily itineraries, reservations, weather-aware outfit planning, rental-car details, to-do lists, and multi-currency expense tracking.

## Install

Open the GitHub Pages link in Safari on iPhone or Chrome on Android, then choose **Add to Home Screen** / **Install app**.
